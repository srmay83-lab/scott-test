# Family Diary

A shared household planner for the kitchen iPad and family phones: the week at a glance, each day's meals, plans and reminders, and a shared shopping list. Changes sync between devices within a second or two.

- `index.html` is the whole app.
- `config.js` holds the Firebase connection settings and the shared login email.
- `firestore.rules` holds the database security rules to paste into Firebase.

See [SETUP.md](SETUP.md) to get it running.
